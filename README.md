FRACTAL GENERATOR (C++ & QT6)

Interaktywna aplikacja desktopowa do generowania i eksploracji zbioru Mandelbrota.

TECHNOLOGIE
Jezyk: C++17 Framework: Qt6 Widgets System budowania: CMake 

KLUCZOWE FUNKCJONALNOSCI
Implementacja algorytmu Mandelbrota z wykorzystaniem mapowania przestrzeni barw HSV dla wizualizacji iteracji. Obsluga plynego zoomu pod kursorem myszy oraz przesuwania widoku. Zastosowanie timera do ograniczania częstotliwości przeliczania grafiki podczas ruchu myszą w celu optymalizacji 
uzycia procesora. Połączenie ramy okna zdefiniowanej w formacie XML (mainwindow.ui) z dynamicznie budowaną warstwą prezentacji w kodzie C++.

Wymagany zainstalowany framework Qt6 oraz CMake.
