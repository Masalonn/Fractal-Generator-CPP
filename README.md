FRACTAL GENERATOR (C++ & Qt6)
An interactive desktop application for generating and exploring the Mandelbrot set.

TECHNOLOGIES
Language: C++17

Framework: Qt6 Widgets

Build System: CMake

KEY FEATURES
Implementation of the Mandelbrot algorithm using HSV color space mapping to visualize iterations.

Support for smooth zooming under the mouse cursor and panning the view.

Usage of a timer to limit the graphic recalculation rate during mouse movement to optimize CPU usage.

Integration of the window frame defined in XML format (mainwindow.ui) with a dynamically built presentation layer in C++ code.

Requirements: Installed Qt6 framework and CMake.
